Role-Based Access Control (RBAC)

Simulate a patient granting temporary examination access to an optometrist using Soroban's native require_auth().

SOROBAN EXECUTION LOG • LIVE STATE 
// Call contracts/vision_records::grant_access()
fn grant_access(env: Env, patient: Address, doctor: Address, ttl: u64) {
    patient.require_auth();
    
    let grant = AccessGrant {
        granted_at: env.ledger().timestamp(),
        expires_at: env.ledger().timestamp() + ttl * 3600,
        active: true,
    };
    
    env.storage().persistent().set(&(patient, doctor), &grant);
    env.events().publish(("access", "granted"), (patient, doctor));
}

Core Smart Contract Modules

RetinaX consists of 25 modular Rust smart contracts compiled to WASM and deployed on the Stellar Soroban network.

👁️

Vision Records

contracts/vision_records

Manages patient exam history, refraction parameters, and role-based access permissions (`require_auth()`).

🛡️

ZK Verifier

contracts/zk_verifier

On-chain Groth16 zk-SNARK verification engine for anonymous eligibility proofs and zero-knowledge voting.

🤖

AI Integrator

contracts/ai_integration

Automated provider failover and weight rotation oracle for AI-assisted diagnostic evaluation.

🌉

Cross-Chain Bridge

contracts/cross_chain

Merkle proof validation and refund resilience flows for cross-chain state synchronization.

🏥

FHIR & EMR Bridge

contracts/fhir & emr_bridge

Bidirectional mapping between Soroban structs and international FHIR v4 / LOINC medical record standards.

⚖️

Compliance

contracts/compliance

GDPR Art. 25 data transit policy enforcement, regional blacklisting, and HIPAA consent tracking.
